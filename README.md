# NLP Lab Programs

This repository contains Natural Language Processing (NLP) lab programs implemented using Python. It includes basic NLP techniques, text processing, machine learning methods, and transformer-based applications.

## Programs Included

### CO1: Basic NLP Programs

1. `01_tokenization_nltk_spacy.py` — Tokenization using NLTK and spaCy
2. `02_stemming_lemmatization.py` — Stemming and Lemmatization
3. `03_stopword_removal.py` — Stop-word Removal
4. `04_pos_tagging.py` — Part-of-Speech Tagging
5. `05_parsing_chunking_regex_spacy.py` — Parsing and Chunking using RegEx and spaCy
6. `06_named_entity_recognition_spacy.py` — Named Entity Recognition using spaCy

### CO2: NLP and Text Processing

7. Coreference Resolution
8. Bag-of-Words (BoW)
9. TF-IDF and BoW Comparison
10. Unigram, Bigram and Trigram Models
11. Cosine Similarity
12. Word2Vec using Gensim
13. GloVe Word Embeddings
14. Word Mover's Distance
15. Text Classification using TF-IDF
16. Sentiment Analysis
17. Topic Modelling using LDA
18. Latent Semantic Analysis (LSA)
19. Opinion Mining
20. Information Extraction
21. Information Retrieval using TF-IDF
22. RNN/LSTM Sequence Classification
23. Basic Attention Mechanism

### CO3: Transformer-Based NLP Applications

24. Text Classification using BERT
25. Sentence Embeddings
26. Text Generation using GPT-2
27. Named Entity Recognition using Transformers
28. Machine Translation
29. Text Summarization
30. Chatbot using a Pretrained Conversational Model
31. Automatic Document Classification

### Additional Program

32. Document Boundary Detection using Rules and a State Machine

## How to Run

1. Open Google Colab or a Python environment.
2. Open the required `.py` file or `.ipynb` notebook.
3. Install the required libraries if they are not already installed.
4. Download any required language models or pretrained model files.
5. Run the program and observe the output.

## Notes

- Some programs require an internet connection to download pretrained models.
- Program 13 requires a GloVe word-vector file.
- Some programs may require additional package setup.
- These programs are intended for educational and lab practice.

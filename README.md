# NLP Unit 1 Programs

This repository contains the six NLP Unit-1 lab programs.

## Programs

1. `01_tokenization_nltk_spacy.py` - Tokenization using NLTK and spaCy
2. `02_stemming_lemmatization.py` - Stemming and Lemmatization
3. `03_stopword_removal.py` - Stop-word Removal
4. `04_pos_tagging.py` - Part-of-Speech Tagging
5. `05_parsing_chunking_regex_spacy.py` - Parsing and Chunking using RegEx and spaCy
6. `06_named_entity_recognition_spacy.py` - Named Entity Recognition using spaCy

## How to Run in Google Colab

1. Open Google Colab.
2. Create a new notebook.
3. Copy the required program into a code cell.
4. Run the installation commands shown at the top of the program.
5. Run the program.
6. Save/download the notebook as `.ipynb` if your submission requires a notebook.
7. Take screenshots of the code and output if your teacher requires them.
